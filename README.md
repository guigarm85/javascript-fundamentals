
# JavaScript Fundamentals

I organized this collection of JavaScript examples to practice programming fundamentals and strengthen my understanding of the language.

I worked with conditions, loops, functions, strings, objects, arrays, JSON, error handling, and basic asynchronous programming. Each example focuses on a specific concept.

## Practice Examples

| Example | What I practiced |
|---|---|
| [Data types](practice/01-data-types.js) | Values and `typeof` |
| [Comparisons](practice/02-comparisons.js) | Equality, inequality, and relational operators |
| [Ticket prices](practice/03-ticket-prices.js) | `if`, `else if`, and logical conditions |
| [String methods](practice/04-string-methods.js) | Case conversion, `trim`, and method chaining |
| [Rectangle area](practice/05-rectangle-area.js) | Function parameters and return values |
| [Sum with a for loop](practice/06-sum-with-for.js) | Loop counter and accumulator |
| [Break and continue](practice/07-break-and-continue.js) | Stopping a loop and skipping an iteration |
| [Objects](practice/08-objects.js) | Properties, updates, and adding a property |
| [Array methods](practice/09-array-methods.js) | `push`, `pop`, `shift`, and `unshift` |
| [Array transformations](practice/10-array-transformations.js) | `forEach`, `map`, `filter`, and `reduce` |
| [JSON data](practice/11-json-data.js) | Parsing JSON, updating an array, and stringifying |
| [Division errors](practice/12-division-errors.js) | `throw`, `try`, and `catch` |
| [Callback](practice/13-callback.js) | Passing a function as an argument |
| [Promises](practice/14-promises.js) | `then` and `catch` with a simulated rejection |
| [Async and await](practice/15-async-await.js) | `Promise`, `setTimeout`, and `await` |

## Technologies

- JavaScript
- Node.js

## Getting Started

1. Install Node.js.
2. Open the project folder in a terminal.
3. Run any example, such as:

```bash
node practice/05-rectangle-area.js
```

Each example can be run independently without additional packages. Some asynchronous examples may display their results after a short delay.
